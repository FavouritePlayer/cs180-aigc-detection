# Dataset attribution and reuse

Source: [WasItAIGenerated Frontier Image & Video Benchmark (2026–10)](https://huggingface.co/datasets/wasitaigeneratedcom/frontier-image-video-bench-2026-10), revision `e6a8b83d15fab1da958848368fcd07e943afafd0`.

The publisher's dataset card states: “AI-generated files: CC BY 4.0 (WasItAIGenerated). Real files keep their original license, listed per file in `metadata.csv` with author and source; CC BY and CC BY-SA files require attribution to the listed author when reused.”

The [sample manifest](../../stage2/frontier_manifest.json) preserves the benchmark's license, author and original source URL for every selected file. Original image bytes are not redistributed here. The report credits each displayed example and identifies its resizing/derived visualizations. Licenses remain with their respective original authors; the dataset's mixed licenses do not change the license of unrelated project code.
